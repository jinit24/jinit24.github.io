Pluto Support

Let's get you unstuck.

Start with the fixes below. If the problem continues, open a support request with the app version, iOS version, and the steps that led to it.

Common fixes

Gmail will not connect

Confirm you are online, retry from Settings → Connect Gmail, and verify Pluto still has access in your Google Account.

A receipt is missing

Run a recent sync, search the Timeline, then add or attach the receipt manually if the sender is not recognized.

Access is not showing

Open Settings → Manage access and choose Restore purchases while signed into the Apple Account that made the purchase.

Request support

Support requests on GitHub are public. Never include email text, receipts, merchant names, transaction amounts, Google tokens, passwords, or banking information.

Open a support request

Privacy and data deletion

Disconnect Gmail or delete local Pluto data from Settings → Privacy center. For details, read the Pluto Privacy Policy.
